# Desenvolvimento Web – Semana 03

Resolução dos desafios de Introdução ao JavaScript.

## Arquivos

- `bloco 1.js`: variáveis, tipos e template literals
- `bloco 2.js`: funções (declarada, expressão, arrow, parâmetro padrão)
- `bloco 3.js`: `if/else`, `switch`, `for`, `while`

## Como executar

```bash
node "bloco 1.js"
node "bloco 2.js"
node "bloco 3.js"
```

Ou cole cada arquivo no console do navegador.

## Erros de propósito

- `bloco 1.js`: reatribuir `MAX_PONTOS` gera `TypeError`.
- `bloco 2.js`: chamar `ehMaiorDeIdadeExpressao` antes da declaração gera `ReferenceError`.
